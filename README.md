# Wynny
Wynny is a Discord chatbot that has various commands.

# Commands

## !help
Sends a list of available commands.

## !dog
Sends an image of a dog and a fun fact.

## !cat
Sends an image of a cat and a fun facts.

## !dadjoke
Tells a random dad joke.

## !csjoke
Tells a random cs joke.

## !fortune
Reads a fortune cookie.

## !8ball
Gives an answer to a yes/no question.
